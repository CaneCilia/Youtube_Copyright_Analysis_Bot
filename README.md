# 🛡️ Copyright Detector Bot (Streamlit)

A tool to detect copyright-infringed media uploaded via UI. Currently supports:
- Image fingerprinting using perceptual hashing
- Owner matching from a sample database
- Simple UI built with Streamlit

## Setup

```bash
pip install -r requirements.txt
streamlit run app.py
''
